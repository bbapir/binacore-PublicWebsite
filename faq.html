FAQ

Short answers

General

Which platforms does Binacore run on?

Binacore Desktop runs on Windows and macOS. Binacore App runs on Android and iOS.

Who is Binacore for?

Structural engineers in practice, researchers and students.

Which units can I work in?

Binacore Desktop has seven consistent unit sets and converts between them. Binacore App works in metric and imperial.

How do I know the results are right?

Results are checked against theoretical solutions, independent hand calculations and the reference models of OpenSees. How Binacore is checked

How do I report a problem or suggest a feature?

Write to us. Every message is read. Contact

Binacore Desktop

Do I need to install OpenSees?

Yes. Binacore Desktop runs its analyses in OpenSees through OpenSeesPy, which you install yourself. See Install

Which analyses can I run?

Static, modal, pushover, time history and response spectrum, linear and nonlinear. One case can continue from another, such as a pushover after gravity.

Can I model nonlinear behaviour?

Yes. Fibre sections, plastic hinges and more than fifty OpenSees materials, each with a response plot you can test before you use it.

Which ground motion files can I load?

PEER .AT2 records, time and acceleration in two columns, one or several values per line, and CSV.

Can I see what is sent to OpenSees?

Yes. Every model exports as a plain OpenSeesPy script that you can read, run and change.

Can I export results?

Tables as CSV. Plots as PNG, PDF, SVG or CSV. Animations as GIF or MP4.

Where do I start?

With a worked example under File, Examples, or with First steps

Binacore App

Which design code does Binacore App use?

ACI 318M-25. Every check names the clause it comes from.

Does Binacore App need a connection?

No. The analysis and the design run on the phone.

Can I follow how a result was reached?

Yes. Each check shows its clause, the values that went in and the result.

Can I save and share a design?

Yes. Designs are saved on the phone and export as a PDF report.

Is there a dark mode?

Yes. Light and dark, chosen in Settings.
