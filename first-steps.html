First steps

Your first model, start to finish

Binacore Desktop

  1. Model

    Set the grids and storeys, then draw the members or generate a frame.

  2. Members

    Define materials and sections, and assign an element type to every member.

  3. Loads

    Add load patterns, masses and, for a time history, a ground motion.

  4. Analysis

    Create the cases you need: static, modal, pushover, time history. The model is checked before it runs.

  5. Results

    Read deformed shapes, force diagrams and contours on the structure, at any step.

Binacore App

  1. Geometry

    Enter the spans, the supports and the cross-section.

  2. Analysis

    Add the loads and read the moments and shears.

  3. Design

    See the reinforcement and every check, each with its clause.

  4. Report

    Export the whole design as a PDF.
