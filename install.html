Install

Set up in a few steps

Binacore Desktop

  1. Download

    Get the installer for Windows or macOS and run it.

  2. Install OpenSeesPy

    OpenSees does the analysis and is installed separately, in Python: pip install openseespy

  3. Point Binacore to it

    In Edit, Settings, choose the Python that has OpenSeesPy.

  4. Run an example

    Open one from File, Examples, and run it.

Download for desktop
Binacore App

  1. Download

    Get the app for Android or iOS.

  2. Open it

    There is nothing else to set up. The whole design runs on the phone.

  3. Start with an example

    The home screen has a worked example for every kind of member.
